# User Stories

## Rider planning a trip
As a late-shift rider, I want to select my station, route, departure window, and match preference so I can find people traveling in a similar direction.

## Rider seeking companionship
As a rider, I want to see compatible Virtual Buddies using aliases and broad route information so I can decide whether to request a match without sharing my identity or destination.

## Rider feeling anxious
As a rider, I want a quick grounding tool and a brief supportive AI response so I can feel more regulated while waiting or traveling.

## Rider using comfort audio
As a rider, I want to play a realistic but clearly non-emergency comfort audio clip so I can feel less isolated in an uncomfortable moment.

## Rider needing urgent help
As a rider, I want prominent official emergency and transit safety resources so I can make a fast, informed decision.

## Community impact viewer
As a program partner or transit advocate, I want anonymized aggregate trend data so I can understand when and where riders request support without seeing anyone's identity or exact location.

## Acceptance criteria
- Users can complete the core flow in under 90 seconds.
- No screen requires real data to be demoable.
- The app remains usable without sponsor API keys using deterministic fallback data.
- All safety-related language is bounded, clear, and non-alarmist.
